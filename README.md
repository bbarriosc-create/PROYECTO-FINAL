# Proyecto Final - Sistema de Ventas e Inventario

## Descripción

Este proyecto fue realizado en C++ para el curso de Programación II.

El sistema permite llevar el control de productos y ventas de una tienda mediante archivos binarios. También incluye reportes, búsquedas, ordenamientos y algunas utilidades para facilitar la administración del inventario.

## Funciones del sistema

### Gestión de productos

- Registrar productos
- Mostrar productos registrados
- Buscar productos por código
- Buscar productos por nombre
- Actualizar stock
- Modificar precios
- Eliminar productos

### Ventas

- Crear ventas
- Agregar varios productos a una venta
- Validar existencia de stock
- Calcular subtotal
- Aplicar IVA
- Aplicar descuentos automáticos
- Actualizar inventario después de cada venta

### Reportes

- Producto con menor stock
- Producto más vendido
- Ventas realizadas por día
- Ventas por mes
- Ordenamientos por precio, stock y ventas

### Utilidades

- Exportar reportes a archivo TXT
- Reiniciar inventario
- Mostrar estadísticas generales

## Estructuras utilizadas

- Producto
- Venta
- DetalleVenta

## Archivos utilizados

- productos.dat
- ventas.dat
- detalleVentas.dat
- reporte.txt
